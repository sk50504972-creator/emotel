# 이모텔 고객용 앱 (PWA)

순천 연향동 이모텔(E MOTEL) 손님이 휴대폰 홈 화면에 설치하는 안내 앱.

- 주소: https://balhae.claimworks.kr/emotel/
- 기능: 전화, 길찾기(카카오맵·네이버지도), 예약(여기어때·야놀자), 이용 시간, 주차, 객실 안내, 내 객실 퇴실 카운트다운(손님 휴대폰에만 저장)
- 정보 수정: index.html 안 `INFO` 블록만 고치면 된다. 수정 후 sw.js의 CACHE_VERSION을 올린다.
- 정보 출처: 순천시청 숙박정보(e이모텔 061-725-4848, 연향상가2길 4), 여기어때 「순천 e」 공개 정보 (2026-09-28 확인)
